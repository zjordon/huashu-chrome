# huashu-chrome 使用指南

> 分析日期：2026-09-15 · 版本：v1.2.0 · 基于源码与 README 整理

## 1. 它是什么

让任何支持 MCP 的 AI agent 操控**你自己日常用的 Chrome**——带着你全部的登录态。一个 npm 包 + 一个 Chrome 扩展，22 个浏览器工具。与无头浏览器方案的本质区别：agent 以你的身份、在你正开着的浏览器里干活，后台标签页执行、不打断你。

```
你：帮我把这份 CSV 里的 30 条客户信息录进 CRM
agent：（打开你已登录的 CRM，逐条填表提交）
```

## 2. 环境要求

| 项 | 要求 |
|---|---|
| Node | ≥ 20（`package.json` engines） |
| Chrome | ≥ 116（扩展 manifest `minimum_chrome_version`） |
| agent | 任何能配本地 MCP server 的：Claude Code、Codex CLI、Cursor、Gemini CLI、Windsurf、Cline 等 20+ 家 |
| 平台 | Windows / macOS / Linux（install 的配置路径三平台已适配） |

## 3. 安装

### 3.1 一键安装（推荐）

```bash
npx huashu-chrome install
```

一条命令做三件事：

1. **检测 agent**：三层识别——已知表（`src/agents.json` 20 家：Claude Code、Codex、Cursor、Gemini、Claude Desktop、Windsurf、Cline、Roo、WorkBuddy、CodeBuddy、Kimi Code、通义灵码、Mavis、Trae、豆包、千问、Qoder、DeepSeek、iFlow、OpenClaw）→ 自动发现（扫 home 点目录里含 `mcpServers` 的配置，未列出的新产品也能认）→ 都不匹配则打印 JSON 让你自己贴
2. **写 MCP 配置**：动手前每个文件先备份成 `<文件名>.bak-<时间戳>`；已配过的跳过。`--dry-run` 只看计划不写；`--only claude-code` 只配指定一家
3. **弹引导页**：教你装扩展

装扩展这步**必须自己点**（浏览器不允许脚本代劳）：

- 商店一键装：`https://chromewebstore.google.com/detail/foiljmaplphdfimfcnfdpekhdnfbgfbf`
- 或手动：`npx huashu-chrome extension --reveal` 在文件管理器里选中扩展目录 → `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序

### 3.2 验证

```bash
npx huashu-chrome doctor
```

看到「握手正常 · Chrome 扩展在线」即成。桥进程由 agent 首次调用自动拉起，**不需要手动开任何常驻东西**。装完 agent 需重启一次才会加载新 MCP server。

### 3.3 手动配置（不想让 install 碰配置文件）

**Claude Code**
```bash
claude mcp add huashu-chrome -- npx -y huashu-chrome mcp --client claude-code
```

**Codex CLI**（`~/.codex/config.toml`）
```toml
[mcp_servers.huashu-chrome]
command = "npx"
args = ["-y", "huashu-chrome", "mcp", "--client", "codex"]
```

**Cursor / Gemini CLI / Windsurf / Claude Desktop**（各自 JSON 配置）
```json
{ "mcpServers": { "huashu-chrome": { "command": "npx", "args": ["-y", "huashu-chrome", "mcp"] } } }
```

`--client` 可以不写：页面右下角和审计里显示的是宿主在 MCP 握手里自报的身份，该参数只在宿主没报时兜底。

## 4. 22 个工具速览

MCP 握手时 server 会下发策略（三层信息载体顺序、批处理优先、标签页纪律），agent 不需要你教。

### 数据层（要数字、列表、表格，从这里开始）

| 工具 | 干什么 |
|---|---|
| `network` | 看页面调了哪些接口、返回什么。`body:"<url片段>"` 取响应体，`index` 往回数页。字段名是站方写的，不用猜 |
| `fetch` | 带你的 cookie 调接口。`pages` 一次翻完所有页（页码或游标），`binary` 取图片 |
| `download` | 大文件走浏览器原生下载，不占内存、不弹保存框 |

### 操作层（要做事、读文章）

| 工具 | 干什么 |
|---|---|
| `snapshot` | 拍带 ref 编号的可交互元素清单（含 value/checked/selected/expansion/disabled），一页 1–2k token |
| `fill` | 一次填完整张表并提交 |
| `click` `type` `select` `key` | 按 ref 操作，返回新快照；`expect` 校验「变成我要的样子没有」；画布/游戏用 `click {x,y}` 真实坐标 |
| `navigate` `tabs` `wait` `scroll` | 导航、标签页（后台开新页+label）、等待、滚动加载 |
| `read_text` | 正文提取成 markdown，去掉导航页脚广告 |
| `query` | CSS selector 结构化提取；`contains` 按文本找元素 |
| `upload` | 本地文件塞进网页上传框（系统文件对话框扩展够不着，这是唯一的路） |
| `eval` | 页面里跑 JS，受页面 CSP 管 |

### 批处理 / 人 / 兜底

| 工具 | 干什么 |
|---|---|
| `act` | 一次调用跑完多步（repeat/if/assert 控制块），每步验效果，撞上提交/支付/删除即停 |
| `ask` | 验证码、扫码、短信验证码、需要你拍板的事——浮条+高亮+桌面通知，等你 |
| `status` | 给用户看的一句话声明（驾驶舱显示） |
| `learnings` | 查/存站点经验（开工前查，收工时存） |
| `screenshot` | 版式本身有问题时才用；默认 60% JPEG 省 token |
| `reload` | 改了扩展代码后让扩展自己重载 |

## 5. 典型用法

### 5.1 让 agent 干活（你只说话）

```
「查一下这本书在京东有几家在卖，评价怎么样」
「把这篇稿子发到小红书，配这 9 张图，明早 7:30 定时发」
「明天武汉到上海的高铁还有没有二等座，顺便告诉我票价」
「把这份表格里的记录加进飞书多维表格」
```

agent 的标准开局（由握手 instructions 驱动，无需人工干预）：`learnings(domain)` 查经验 → `tabs(action:"new", label:...)` 开后台标签页 → `network` 找数据接口 / `snapshot`+`act` 做操作 → 遇到验证码 `ask` 交还给你 → 收工 `learnings(domain, save)` 回流经验。

### 5.2 开发调试（不经 agent 直接发命令）

```bash
npx huashu-chrome call snapshot
npx huashu-chrome call tabs '{"action":"new","url":"https://example.com"}'
npx huashu-chrome call click '{"ref":"e3","snapshotId":"s1"}'
npx huashu-chrome call learnings '{"domain":"jd.com"}'
```

### 5.3 审计与观测

```bash
npx huashu-chrome audit -n 50        # 最近 50 条浏览器操作
npx huashu-chrome audit --stats      # 真实 agent 用法统计：回合空档、命令分布、错误 Top
npx huashu-chrome audit --stats --days 30
```

审计文件在 `~/.huashu-chrome/audit.jsonl`，密码/验证码类字段只记位数。

## 6. 你会看到什么（可见性）

| 位置 | 长什么样 |
|---|---|
| 标签栏 | 受控页进彩色标签组（组色=会话色），标签挤到最窄也可见 |
| 页内 | 同色描边 + 呼吸泛光箭头 + 右下角驾驶舱（正在做/准备做/时间线） |
| 扩展弹窗 | 会话列表（谁在控哪一页）、连接状态、重连按钮、高保真开关 |
| 支付时 | 确认卡 + 标签页切前台 + 桌面通知，没人应答按拒绝处理 |

agent 自己的截图看不到这些标记（截图幕帘）。录屏嫌碍事可在弹窗一键关闭。**驾驶舱绝不显示输入的内容**（可能是密码）。

## 7. 排错

| 症状 | 原因 | 处理 |
|---|---|---|
| `NO_EXTENSION` | 扩展到桥的连接断了（插件本身没消失） | 点工具栏图标 → 「重连」；Chrome 没开先开；只有改过扩展代码才去 `chrome://extensions` 重载 |
| `NEEDS_L2` | 这步要真实输入事件，高保真模式没开 | 扩展图标 → 「高保真模式」开启（一次即可） |
| `L2_BUSY` | 调试器被占用（多半你自己开着 DevTools） | 关 DevTools；已自动降级 |
| `STALE_SNAPSHOT` | 页面变了，ref 全作废 | 正常，agent 会自己重拍 |
| 命令全卡 | 页面有 alert/confirm 挡着 | 手动关掉弹窗 |
| `chrome://` 页没反应 | 浏览器保护页注入不了（Chrome 商店页同类） | 换普通网页 |
| 桥拉不起来 | 端口占用/看日志 | `~/.huashu-chrome/bridge.log`；查 8899 端口占用 |
| 命令跑到另一个 Chrome | 多实例连着桥 | doctor 会列出实例并标注主路由，headless 孤儿进程可 kill |

改了 `src/bridge.js` 又没动版本号：桥是长驻单例，起来后不读磁盘——手动杀掉进程，下一条命令拉起新的。改了 `extension/`：`node src/cli.js call reload '{}'` 让扩展自己重载。

## 8. 开发

```bash
git clone https://github.com/alchaincyf/huashu-chrome
npm install
npm test              # 16 个测试文件：协议与安全边界，不需要浏览器
npm run test:live     # 交互场景回归，需要 Chrome + 已装扩展（本地靶场 test/fixtures/playground.html）
node src/cli.js bridge --foreground   # 前台跑桥（调试）
node scripts/pack-extension.mjs       # 打 Web Store 上传包（自动剥 manifest key）
```

- 测试无需浏览器即可覆盖安全逻辑（脱敏/风控判定/剧本校验是纯函数模块，Node 侧直接 import）
- 发布：`npm version patch && git push --follow-tags` → CI（OIDC 可信发布）自动 npm publish；本地不要手动 publish
- 给项目加一个 agent 支持：往 `src/agents.json` 数组加一行，不用改代码（欢迎 PR）
- 给经验库贡献：把 `~/.huashu-chrome/learnings/` 的文件 PR 到 `docs/经验/`，**先检查有没有把你自己的账号/行程/订单号写进去**

## 9. 隐私与安全边界

- 所有数据在本机：`~/.huashu-chrome/`（审计、经验、桥信息）；经验不上传
- 每条命令落审计，敏感输入脱敏；页面文本对 agent 降权（防 prompt injection）
- **会花钱的动作有人把关（扩展侧确认卡，agent 无参数可跳过），会删东西的没有**——接公司后台前想清楚
- 详细隐私声明见 `PRIVACY.md`
